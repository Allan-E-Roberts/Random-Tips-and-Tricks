# Obsidian is quite possibly the best note-taking application ever.

## Basics:  
Obsidian uses Markdown. All my Markdown tips apply, but so much more as well.  

## Create a navigation menu
You can crate a custom navigation menu, then reference it in any note you desire with an exclamation point followed by the double bracket link to show it in that note.  

For example, I want all of my notes to link to: [HOME], [Calendar], and [Daily Checklist].  
  * I could manually type these links in every time, or I could create a [NAV] note and put them in there.  
  * An example of this would look like: ```[[Home]] [[Calendar]] [[Daily Checklist]]```  

Of course, that's just the tip of the iceberg. I like having icons in my NAV note, so I created a table with all of the icon images underneath the link to that note, then put all of that under a NAV header so I can collapse it when it's not needed.

Some additional quick tips:
  * The \<br\> elements are HTML code to add a new line.  
  * The "|100" after each image sets the size to 100 pixels (technically rem is gernally preferred in most cases, so if you do web dev, use rem, not pixels). Adjust this to the size you desire.  
  * Markdown tables use pipes "|" to indicate separators between colums. The top row usually has titles, but I don't use that for a grid of icons. The second row is there to indicate the break between titles and everything else. The empty titles trick is a well-known Markdown trick.  
  * If you are finding it hard to navigate back and forth when editing Obsidian references on mobile, switch to a code block so it stops rendering links. This can make it much easier, especially if you use a bluetooth keyboard and mouse with your mobile device when you do coding like this.
  * Keep all of your references (icons, images, custom bullets, custom dividers, etc) in a seperate folder. I tend to use REFS/Icons, REFS/Images, REFS/DND_monster_profiles, et cetera since these types of files can get messy quickly, and you need to know the full path to each reference.
  * On a similar note, rename all saved images to something obvious. All of my icons start with the name of the note I want to navigate to (with underscores instead of spaces) and end in _icon (followed by the extension), so if I want to add one but don't remember the name, I can just type \[\[_icon\]\] to get a list of all my icons, then I can select the one I want from that list.


## Decide on HOW you want to use Obsidian, because it can do many things.  
1. Basic notes:  
    * Use square brackets to create links between ideas.  
    * Link anything and everything to create a dense web of ideas (similar to the Wikipedia Game).  
    * Use bookmarks rather than folders to navigate.  
        * Bookmarks have no location nor set relationships to other documents.  
        * They show up in the Bookmarks tab.  
        * Use them to link to any ideas you feel like at any point in time you feel like.  
    * PROS:
        * Fast  
        * Dynamic  
        * Intuitive  
    * CONS:  
        * Harder to manage as the number of notes increases.  
        * Doesn't encourage thinking through an idea as much as writing it down.  
        * Gets cluttered and disorganized very quickly.
    * Recommended applications:
        * Brainstorming
        * Creative thinking

2. Highly Structured folders:
    * Iterative folders to store information
    * Similar to any standard file structure
    * Any specific note can be found quickly
    * May still use links to navigate between related notes, as well as display information in other notes.
    * PROS:
        * Well-structured data is easy to find and manipulate.
        * Works very well with templates.
        * Excellent for tracking changes in data or many documents.
    * CONS:
        * Similar to other note-taking apps, making the transition largely redundant.
        * Does not represent intuitive thought-development as richly.
        * May lead to inaction rather than note-taking, and time spent organizing that could be spent brainstorming.
    * Recommended applications:
        * Work, business, fitness, or other data-driven tracking.
        * Large-scale projects (writing a novel, tracking phases of a project, evaluating finances, etc).

3. Tags:
     * Tags allow notes to be sorted based on any tag or tags you specify.
     * A note may have several different tags (home, finance, projects, last month), all of which may be sorted.
     * Similar to a folder, a tag can represent an overall idea that applies to many things.
     * Similar to a link, a file may have any combination of tags rather than just one.
     * PROS:
         * Tags are versatile and help organize information.
         * Tags can be edited, even in bulk, as a workflow changes.
      * CONS:
         * Tags need to be manually assigned.
         * Tags may quickly become disorganized if left unmanaged.
 
4. Accumulated Reports (what I call them at least):
    * Adding an exclamation point in front of a link will show the contents of the linked document in the current one.
    * An accumulated report may collect several notes (ex: Daily thoughts, Project status, Fitness Routine, Work Reminders) all together in one single document for review.
    * An accumulated report may reference information in other folders, similar to links, but format it similar to folders.
    * An accumulated report gives you an overall rundown of one thing in one place.
    * PROS:
        * Highly detailed overview spanning multiple notes pages.
        * May be expanded or hidden with section headers to show only what's needed at one time.
    * CONS:
        * Requires more setup and more substantial formatting decisions.
        * Difficult to make large changes to, especially if the intent is to change the format of many accumulated reports.
 
5. Combine all three core features:
    * This gives you as much or little flexibility and structure as needed.
    * No one core feature in any way limits how you use another.
    * Folders provide overall categories, not restrictions.
        * Daily notes
        * Book ideas
        * Documents
    * Links provide references, and make it easy to find relevant information within a file.
        * A [character] in a [location] may do something on [Friday the 13th].
        * After increasing [MGSO4 - 7H2O] in my [3rd Spriulina batch] by 50%, I saw 10% faster growth.
    * Tags allow you to sort through all documents to find specific info on one overarching project.
        * The folders: Finances, Projects, and Documents all have (HOUSE) tagged, so searching for (HOUSE) can bring up all of those at once.
        * The folders: Characters, Locations, and Themes may all have (Mystery Novel 01) tagged, so  so searching for (Mystery Novel 01) can bring up all of those at once.
        * Out of all the notes in "Random Thoughts", "Inventions" can be searched for when looking for a new project idea.
