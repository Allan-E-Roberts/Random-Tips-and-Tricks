# 1. Use Unicode

## Purpose: 
Unicode includes a large set of text characters that most tools already have. No importing images, no worrying about link, and no messing around with fonts. Did you know that all emojis are Unicode characters, but emojis are only a small subset of Unicode?

## How to use:    
 * If you are looking for Unicode fonts, I suggest using a converter tool [like this one](https://convertcase.net/unicode-text-converter/). These tools allow you to convert text to Unicode quickly without having to look up different character sets or copy and paste individual characters.  
 * If you use individual Unicode characters for formatting, consider creating a cheatsheet with your favorite characters.
 * If you have navigation buttons, use Unicode arrows.

# 2. Use links:

## Purpose: 
Links can improve navigation, especially when you have a local reference that doesn't belong in a navigation menu.  
Links can display images, allowing you to add more complex formatting.

## How to use:
The text you want to show goes in square brackets \[Like this\]  
The link to the page you want goes in parentheses like this \[Like this\](https://google.com) which renders to: [Like this](https://google.com)  
Always include "https://" before the link so all markdown renderers know that it's a link.  

Images require an exclamation mark to instruct the renderer to render the link.  
The following is the example by GitHub on the official [GitHub Markdown Guide](https://github.com/adam-p/markdown-here/wiki/markdown-cheatsheet).  
\!\[alt text\](https://github.com/adam-p/markdown-here/raw/master/src/common/images/icon48.png "Logo Title Text 1")  
Rendered: ![alt text](https://github.com/adam-p/markdown-here/raw/master/src/common/images/icon48.png "Logo Title Text 1")

# 3. Combine effects, but only when needed.  
Markdown has several effects that can stack together to produce useful formatting.  
Be careful!
 * Some formatting can make a concept easier to understand.  
 * Too much can be distracting or overwhelming.

Have you ever wished you could display text as monospace? The code notation \`\`\` \[code here] \`\`\` renders text as monospace automatically.  

What I want is a border around center-aligned text. If I just type it out, normally, this is what I get:  
⎧‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾⎫  
⎪    This is a test     ⎪  
⎨   of monospace text   ⎬  
⎪  Using code notation  ⎪  
⎩▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁⎭  

Instead, I add three backticks "`" before and after to denote code.  
```
⎧‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾⎫  
⎪    This is a test     ⎪  
⎨   of monospace text   ⎬  
⎪  Using code notation  ⎪  
⎩▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁⎭  
```

Now, I can ensure that the expanded curly brace Unicode characters line up properly, and render the spaces to create a center-align effect.  
This may not seem all that useful at first, but I have used tricks like this (ex: code block + Unicode block-drawings) to represent ladder diagrams for machine logic in the past when I wanted to communicate with programmers using different software.  
There are many applications for tricks like this, so it's useful to play around and see what works with what.
