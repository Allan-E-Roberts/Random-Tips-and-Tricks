# A table can include references
```
|   |   |   | 
|---|---|---|
|![[This]]|![[Is]]|![[A table]]|
|![[Filled]]|![[with]]|![[references]]|

```

If you paste this in outside of a code block, you will get a prompt telling you that none of these references exist. Click on one, type some text, then go back to see it added inside of your table.

Uses: Niche, but varied
Example: Put checklists or important notes from the week into a review table.
    Remember, you can reference a specific section of a note by specifying the section after \# (ex: !\[\[Monday#TasksList\]\])
